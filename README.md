# maqam-toolkit
This is meant to be a project for oriental music where i develop toolkit for arabic maqams  
## Roadmap
- [ ] 1. Drone generator
- [ ] 2. Quarter-tone tuner (YIN, tonic selection, cent deviation)
- [ ] 3. Maqam player: choose a maqam and tonic, hear or play its notes
- [ ] 4. Rhythm machine (maqsum, baladi, saidi)
- [ ] 5. Set player and publishing
- [ ] 6. Optional: compare YIN with CREPE
